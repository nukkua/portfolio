# Marco Salazar — Portfolio

I'm Marco, based in La Paz, Bolivia. Low-level and web.
This is my site. I build tools people use.

## Work

- **zhell** — shell in Zig. `cd, ls, echo, clear, cat, exit`. Custom prompt, manual parsing.
- **Checklo** — check + love. Shared todos for couples with calendar and romantic plans.
- **PRE-COS** — premilitar lookup for Ministerio de Defensa de Bolivia. Check by CI, staff handles inscription and region assignment.

Links go to GitHub. No case-study fluff.

## Stack

Next.js 16, Tailwind v4, no UI library.

Design tokens in `app/globals.css`:
paper `#FAF6EF`, ink `#191817`, spot `#B93A16`.
Fonts: Instrument Serif for headlines, Geist for body/mono.

## Run it

```bash
pnpm dev
```

Edit `app/page.tsx`. That's the whole site.
